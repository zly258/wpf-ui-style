# 几何手册 · 形状配方与反面案例

本文件回答「这个功能该画成什么」以及「为什么这个图标在 16px 下糊了」。
所有配方都基于 24×24 网格、stroke 2、round cap/join。

---

## 1. 基元与笔画预算

| 基元 | 典型用途 | 注意 |
|---|---|---|
| `rect` | 方框、文档、屏幕、选区、锁体 | `r=1` 内框，`r=2` 外框；同一图标只用一种圆角 |
| `circle` | 齿轮位、端点、准星、放大镜 | 半径 ≥ 3，小于 3 在 16px 下退化成点 |
| `line` | 轴线、边界、刻度、对称轴 | 端点由 round cap 补圆，不需要额外画点 |
| `path` | 箭头、勾、折线、弧、复合轮廓 | 一条 path 可含多个 `M` 子路径，算 1 个元素 |

预算（硬上限见 `check`）：

- 独立元素 ≤ **4**；≥ 5 个元素时，优先合并成一条 path 或删掉点缀。
- 每条 path 的坐标点 ≤ ~14；超过说明把「材质细节」画进来了。
- 虚线只作为**一个**修饰元素存在，不能既虚线又要内部点缀。

## 2. 核心几何 + 修饰符

软件图标 = 名词（核心几何）+ 动词（修饰符）。

| 名词核心 | 可搭配的动词修饰 |
|---|---|
| 文档（折角页） | 加号=新建、箭头=导入导出、双层=批量 |
| 方框 | 虚线=框选、双层=批量选择、角括号=缩放适合 |
| 立方体 | 虚线面=剖切、三条棱=三维视图 |
| 箭头 | 回环=撤销重做、切向=旋转、短箭头+边界=延伸 |
| 圆 | 缺口+箭头=旋转、十字=捕捉、柄=放大镜 |

**不要把两个名词叠在一起**（例如「文档 + 齿轮」），那会变成两个图标的信息量，
在 16px 下必然糊。需要表达「批量导出」时，选信息量更大的那个（文档叠层），
导出由所在分组标题表达。

## 3. 常用配方（可直接抄）

### 3.1 框选 / 批量选择

```json
[ { "kind": "rect", "x": 3, "y": 3, "w": 18, "h": 18, "r": 2, "dash": "2 3" },
  { "kind": "rect", "x": 8, "y": 8, "w": 8, "h": 8, "r": 1 } ]
```

- 外框用 `3..21`，即整个安全区，代表「窗口范围」。
- 内框 8×8 放在正中，实体对象必须在**里面**，才能读出「被选中」。
- 批量选择改成两个实心/虚线框错位 5px，表达二次框选叠加。

### 3.2 复制 / 批量 / 阵列

| 语义 | 画法 | 关键 |
|---|---|---|
| 复制 | 实心矩形 + 右下角 L 型错位轮廓 | L 型不闭合，避免读成两个独立文件 |
| 批量 | 完整后层文档 + 完整前层文档 | 前层压住后层 4–5px |
| 阵列 | 源对象 + 右/下两个虚线副本 | 副本必须留 3 单位缝；虚线表示「将要生成」 |

### 3.3 旋转 / 镜像 / 延伸

- 旋转：`M12 6a7 7 0 1 1-7 7`（3/4 圆环）+ 顶部切向小箭头。
  圆环缺口必须 > 60°，否则看起来像断掉的圆；箭头长度 6，不能盖住环。
- 镜像：虚线轴放正中，左右三角形距轴 3px 起，避免和轴粘连。
- 延伸：边界线占满 `3..21`，箭头停在离边界 3px 处——贴住边界会读成「撞墙」。

### 3.4 圆角 / 倒角

```text
圆角: M5 20V10a5 5 0 0 1 5-5h10
倒角: M5 20V10l5-5h10
```

两者只有转角不同，所以**必须共用同一外形骨架**（同为 L 形），否则用户无法对比。
这是「同族图标」原则：同族只允许一处差异。

### 3.5 虚线语义

| 概念 | 虚线放在哪 |
|---|---|
| 框选 | 范围外框 |
| 剖切 | 剖切面整条线 |
| 镜像 | 对称轴 |
| 偏移/参考 | 内层或外层的平行副本 |

虚线不允许出现在「实体对象」上；实体必须是实线。

## 4. 小尺寸退化规则（16px）

16px 时每个设计单位 ≈ 0.67px，以下细节一定消失：

| 设计值 | 16px 实际 | 结论 |
|---|---|---|
| 1px 间隙 | 0.67px | 会粘在一起，最小间隙用 1.5 |
| r=1 圆角 | 0.67px | 看起来还是直角，别指望圆角表达语义 |
| 3px 小圆 | 2px | 只剩一个点，不能承载语义 |
| 2px 虚线间隙 | 1.33px | 可辨，所以虚线用 `2 3` 而不是 `1 1` |

修正顺序：**先删元素 → 再加大间隙 → 最后才整体缩放**。
不要通过把 32px 图形直接 `transform: scale(0.5)` 来适配小尺寸。

## 5. 反面案例

| 反面 | 症状 | 修法 |
|---|---|---|
| 文档里画 4 行横线 + 齿轮 | 16px 是一团灰 | 只留折角页 + 加号 |
| 双线描边（内外各一圈） | 小尺寸下两线合并 | 单线 + 单层虚线 |
| 用填充块做强调 | 与线性体系冲突、主题反色难 | 改用双层错位或短箭头 |
| 箭头尖端画成尖角 | 与 round join 打架，尖端发脏 | 箭头用 2 段 path，靠 round join 自然变圆 |
| 图标写死 `#333` | 深色主题下不可见 | `currentColor` / 继承 `TextElement.Foreground` |
| 每个图标单独调 stroke | 同屏视觉重量不一致 | 全局固定 2 |
| 24 视口里画出 2..22 之外 | 被 Viewbox 裁掉或被描边切边 | 留 3..21 |
| 所有图标都铺满 18×18 | 直线/剪刀被放大，视觉过重 | 固定 24 画布 + 内容按语义占位 |

## 6. 新增图标检查清单

1. `search` 过目录，确认语义没有现成图标可复用。
2. 写出 `concept` 一句话：**核心几何 + 修饰符**；写不出来说明还没想清楚。
3. 用整数/0.5 坐标，先在纸上或 24 网格里点出关键点。
4. 元素 ≤ 4，path 点数 ≤ 14，虚线只出现一次。
5. 跑 `python tools/IconGen.py check --strict`。
6. 跑 `preview`，看 32px 与 16px、深色与浅色四张。
7. 与同组图标并排看视觉重量（方框撑满、剪刀内缩）。
8. 生成 XAML 并在 WPF 里挂到真实按钮上验证继承色。
